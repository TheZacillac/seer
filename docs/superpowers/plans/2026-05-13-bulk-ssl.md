# Bulk SSL Chain Inspection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a new `Ssl` bulk operation that runs deep SSL chain inspection (`SslChecker::check()`) concurrently across many domains, exposed through CLI (`seer bulk ssl ...`), Python (`seer.bulk_ssl`), REST (`POST /ssl/bulk` + stream), and MCP (`seer_bulk_ssl`).

**Architecture:** Purely additive. A new `BulkOperation::Ssl` variant in `seer-core` drives the existing `BulkExecutor` machinery. CLI, Python binding, FastAPI router, and MCP server all mirror the patterns of the existing `bulk status` plumbing — same concurrency caps, same SSRF guards, same streaming helper.

**Tech Stack:** Rust (Tokio, futures, serde), PyO3, FastAPI, MCP. Existing `SslChecker` from `seer-core::ssl`.

**Spec:** `docs/superpowers/specs/2026-05-13-bulk-ssl-design.md`.

```rust
/// SAN limit before truncation in CSV output. A handful of certs have
/// hundreds of SANs (wildcards, CDNs); writing them all into a single CSV
/// cell makes the file unreadable. We keep the first `SAN_DISPLAY_LIMIT`
/// and append `;…+N more` so the column stays truthful about the count.
const SAN_DISPLAY_LIMIT: usize = 10;

/// Joins a SAN list with `;`, truncating to the first `SAN_DISPLAY_LIMIT`
/// entries and appending `;…+N more` when the list is longer.
pub fn join_sans(sans: &[String]) -> String {
    if sans.len() <= SAN_DISPLAY_LIMIT {
        return sans.join(";");
    }
    let head = sans[..SAN_DISPLAY_LIMIT].join(";");
    let remainder = sans.len() - SAN_DISPLAY_LIMIT;
    format!("{head};…+{remainder} more")
}
```

#[pyfunction]
#[pyo3(signature = (domains, concurrency = 10, *, progress = None))]
fn bulk_ssl(
    py: Python<'_>,
    domains: Vec<String>,
    concurrency: usize,
    progress: Option<Py<PyAny>>,

    let executor = BulkExecutor::new().with_concurrency(validate_concurrency(concurrency)?);

    let operations: Vec<BulkOperation> = domains
        .into_iter()
        .map(|domain| BulkOperation::Ssl { domain })

```python
"""SSL chain inspection API endpoints (bulk only)."""

from typing import Annotated

from fastapi import APIRouter, Request
from pydantic import BaseModel, Field

import seer
from seer_api._run import run_seer
from seer_api.errors import http_error
from seer_api.limiting import limiter
from seer_api.ssrf import guard_hosts_async
from seer_api.streaming import stream_bulk

router = APIRouter()

# Bulk operation limits — mirrors status.py.
MAX_BULK_DOMAINS = 100
MAX_CONCURRENCY = 50


class BulkSslRequest(BaseModel):
    """Request model for bulk SSL chain inspection."""

    domains: list[Annotated[str, Field(max_length=253)]] = Field(
        ..., min_length=1, max_length=MAX_BULK_DOMAINS
    )
    concurrency: int = Field(default=10, ge=1, le=MAX_CONCURRENCY)


@router.post("/bulk")
@limiter.limit("5/minute")
async def bulk_ssl(request: Request, body: BulkSslRequest):
    """
    Inspect SSL certificate chains for multiple domains.

    Returns the full SSL report per domain (chain, SANs, key details,
    signature algorithm, TLS version).
    """
    await guard_hosts_async([(d, 443) for d in body.domains])
    try:
        return await run_seer(seer.bulk_ssl, body.domains, body.concurrency)
    except Exception as e:
        raise http_error(e, "Bulk SSL inspection failed")


@router.post("/bulk/stream")
@limiter.limit("5/minute")
async def bulk_ssl_stream(request: Request, body: BulkSslRequest):
    """Stream bulk SSL inspection results as Server-Sent Events."""
    await guard_hosts_async([(d, 443) for d in body.domains])
    try:
        return await stream_bulk(seer.bulk_ssl, body.domains, body.concurrency)
    except Exception as e:
        raise http_error(e, "Bulk SSL stream failed")
```
